# FrameWeave ASR Packs

Optional local ASR packages for [FrameWeave](https://github.com/PCYBlurF) (private app repository).

This repository is for **release assets only**; it does not contain the app source.

## Status

**Preparing.** No ASR binaries or model are published yet.

Publishing requires confirmed upstream provenance and redistribution licenses for:

- whisper.cpp (`whisper-cli.exe`, `whisper.dll`, `ggml*.dll`)
- ffmpeg build
- SDL2
- the GGML model (`ggml-base.bin`)

The current development machine artifacts are mirror-derived and are **not** cleared for redistribution.

## Intended layout

A release named `asr-pack-v1` will contain:

```text
manifest.json
asr-pack-v1.zip
```

The zip is expected to contain:

```text
bin/ffmpeg.exe
bin/Release/whisper-cli.exe
bin/Release/whisper.dll
bin/Release/ggml.dll
bin/Release/ggml-base.dll
bin/Release/ggml-cpu-*.dll
bin/Release/SDL2.dll
models/ggml-base.bin
```

The app will:

1. fetch `manifest.json` over HTTPS;
2. show size, source and licenses;
3. require explicit consent;
4. download to a temporary file;
5. verify size and SHA-256;
6. atomically install to `%LOCALAPPDATA%\FrameWeavesr\<version>\`;
7. allow removal without touching projects or subtitles.

No package is downloaded silently.

## License and provenance policy

Do not upload a build until its source URL, version and license text are recorded in the release notes. The manifest must include a SHA-256 for every asset, generated by the release owner.

## Development

Until a signed/verified pack exists, FrameWeave development uses the local, untracked override:

```text
VB_WHISPER_ROOT=<path containing bin/ and models/>
```
